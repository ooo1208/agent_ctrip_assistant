# 第 1 章：SQLite 合成数据与持久化会话

本章标签：`chapter-01`。这是本次整理的教学快照，不是官方课程章序或回填的历史开发记录。

## 目标

理解业务状态为何需要持久化，而不是只保存在模型聊天记录里。

## 读码顺序

`Store.__init__` → `transaction` → `session` → `append_messages/history`。六张表分别保存会话、消息、航班、酒店、动作和订单；第一章先建立完整数据结构，后续章节逐步接入行为。

## 运行

在仓库根目录执行（不需要第三方依赖和模型密钥）：

```bash
python examples/chapter-01.py
```

## 练习

修改合成航班的出发地，并增加一条消息。关闭数据库再打开后，验证会话 ID 和消息仍一致。

## 完成标准

示例成功显示持久化消息；能够解释参数绑定、外键和写事务的作用。
