# 第 3 章：审批事务、库存复核与幂等执行

本章标签：`chapter-03`。这是本次整理的教学快照，不是官方课程章序或回填的历史开发记录。

## 目标

将人工审批与实际写入绑定，并在同一事务中重新验证业务条件。

## 读码顺序

`Tools.decide` → `Tools.recheck` → `Store.transaction`。重点看 pending/approved/rejected/expired/stale 状态、订单动作唯一约束与逐晚酒店占用。

## 运行

在仓库根目录执行（不需要第三方依赖和模型密钥）：

```bash
python examples/chapter-03.py
```

## 练习

提出两个最后一张机票的提案，先审批其中一个，检查另一个失效。再尝试报价变更、酒店入住区间重叠与重复批准。

## 完成标准

批准产生一笔模拟订单，重复批准返回同一订单且库存只减一次；拒绝不会创建订单。
