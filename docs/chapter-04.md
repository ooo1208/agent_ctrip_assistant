# 第 4 章：工具路由、参数边界与会话恢复

本章标签：`chapter-04`。这是本次整理的教学快照，不是官方课程章序或回填的历史开发记录。

## 目标

让所有命令通过工具白名单和字段校验，并在进程重启后恢复待办状态。

## 读码顺序

`TOOL_PARAMETERS` → `Router.execute` → `offline` → `handle`。本章只有离线入口；下一章才接入真实模型 HTTP 协议。审批仍是单独的显式入口。

## 运行

在仓库根目录执行（不需要第三方依赖和模型密钥）：

```bash
python examples/chapter-04.py
```

## 练习

尝试调用不存在的工具、向订单查询注入 user 字段、缺少乘客参数，以及使用另一用户恢复当前会话。

## 完成标准

错误参数不会创建提案；重开数据库仍能查到同一会话的提案和消息；路由器不能调用 decide。
